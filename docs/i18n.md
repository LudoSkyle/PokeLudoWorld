# Langues

Le jeu est **écrit en français** : les textes des scènes et du code sont en
français, et chaque autre langue est une traduction dans `locale/<code>.po`
(gettext). Aujourd'hui : `locale/en.po`.

La langue se choisit dans Options → Langue ; elle est gardée dans les réglages
(`Settings.language`) et appliquée par `TranslationServer.setLocale`.

## Ce qui se traduit tout seul

- **Les `Label` des scènes** (menus, options, bandeau de lieu) : Godot traduit
  leur texte à l'affichage et le met à jour quand la langue change. Rien à
  coder.
- **La boîte de dialogue** : `MessageBox.play` traduit chaque boîte avant de la
  dire, et le nom de celui qui parle (`display_name`) avec elle. Un PNJ, un panneau ou un meuble garde donc son texte français dans la
  scène.

Un texte fabriqué par le code passe par `T("...")` (`scripts/ui/Texts.kt`),
y compris une phrase à trous : `T("L'horloge indique %d h %02d.").format(...)`.

## Ajouter ou changer un texte

1. L'écrire en français là où il sert (scène ou code).
2. Ajouter son entrée dans `locale/en.po` : `msgid` = le texte français
   **exact**, `msgstr` = l'anglais. Un texte de dialogue se traduit **boîte par
   boîte** : `"A.|B."` donne deux entrées, `A.` et `B.`. Dans un `states`
   (`"drapeau > A.|B."`), le drapeau n'est pas du texte : mêmes deux entrées.
   Une consigne en tête de boîte (`@give:…`, `@take:…`, `@flag:…`, `@reload`) non plus. La question
   d'un `ask` est une entrée à elle seule.
3. Lancer `tests/run.sh i18n` : il relève tous les textes du jeu et signale
   ceux qui n'ont pas de traduction, ainsi que les traductions devenues
   inutiles.

Une liste de textes dits tels quels par la boîte (les émissions de télé) porte
le commentaire `// i18n` au-dessus d'elle pour être relevée.

Sans traduction, le texte s'affiche en français : rien ne casse, mais
`tests/run.sh i18n` le signale. Une boîte tient deux lignes d'environ 43
caractères dans les deux langues.

## Ajouter une langue

Un fichier `locale/<code>.po`, son chemin dans `project.godot`
(`[internationalization] locale/translations`), le code dans
`Settings.LANGUAGES`, et un choix de plus sur la ligne `Language` de
`options_menu.tscn` (son nom s'écrit dans sa propre langue, sans traduction).
