# Le nom des cases de itemdex_kryptonlion.png : « bloc:rangée:colonne  nom [nom…] », en
# hexadécimal, comme sur la planche : 03:1:0 est le bloc 03, rangée 1_, colonne _0.
#
# tools/item_icons.py exporte toutes les cases dessinées de la planche. Une case nommée ici
# va dans icons/named/<nom>.png ; une case sans ligne va dans icons/unnamed/ (ou dans
# icons/invented/ si c'est un objet de Kryptonlion). Nommer une case de plus, c'est lui
# donner une ligne et relancer le script.
#
# Un nom dit quel objet officiel la case représente — jamais à quoi le jeu l'emploie. Le
# jeu se sert du ruban 07:F:2 et de la flèche 00:F:F sans qu'ils aient de ligne ici : il
# les désigne par leur fichier, unnamed/07_F_2_fan et unnamed/00_F_F_special.
#
# D'où viennent ces noms — la planche n'en porte aucun :
#   - 961 cases sont, pixel pour pixel, une icône nommée de pokesprite
#     (github.com/msikma/pokesprite, dossier items/, version du 22/07/2022 : 1074 icônes
#     officielles des générations 3 à 8). Le nom est celui de pokesprite, écrit à notre
#     façon : ball/master devient master_ball, berry/razz razz_berry, tm/fire machine_fire,
#     key-item/town-map-gen3 town_map_gen3. Un suffixe _gen3, _gen4… désigne une ancienne
#     version de l'icône ;
#   - 6 cases sont, pixel pour pixel, une icône nommée de PokeAPI
#     (github.com/PokeAPI/sprites, dossier sprites/items/) : red_orb et blue_orb (00:5:C,
#     00:6:C), machine_hm_fighting (00:8:9), data_card, sparkling_stone, retro_mail ;
#   - 15 cases sont, pixel pour pixel, une CT de notre planche de FRLG (frlg.txt) : les
#     machine_<type> des rangées 2 à 8 du bloc 00 ;
#   - 31 cases ont exactement la silhouette d'une icône de pokesprite ou de PokeAPI, à
#     quelques teintes près, et ont été vérifiées à l'œil une à une : les quatorze objets
#     du Lanceur Miracle (wonder_launcher_potion…), dire_hit_1, les anciennes couleurs de
#     park_ball et lure_ball, key_stone_gen6, red_orb_gen3, blue_orb_gen3,
#     lock_capsule_gen4, travel_trunk_silver, lost_item, xtransceiver_blue,
#     dowsing_machine_xy, fab_mail, pinap_berry_alt (un second dessin de la Baie Nanana),
#     dark_memory, lift_key, basement_key_goldenrod, tm_case (recolorée) ;
#   - 8 cases, que ni l'un ni l'autre n'a, gardent le nom de l'icône de Pokémon Essentials
#     dont elles ont la silhouette et les couleurs : amulet_coin, old_rod, poke_flute…
#
# Plusieurs cases de la planche portent exactement le même dessin (un objet qui reprend
# l'icône d'un autre) : elles ont le même nom ici, et ne donnent qu'un fichier.
