# Le nom des cases de frlg.png : « numéro  nom [nom…] ».
#
# Le numéro est le rang de la case, de gauche à droite et de haut en bas, à partir de 0
# (16 cases par rangée).

# tools/item_icons.py ne garde une case de FRLG que si la planche de Kryptonlion n'a pas
# ce dessin : une case nommée va alors dans icons/named/, une case sans ligne dans
# icons/unnamed/frlg_<numéro>.png. Presque toutes sont écartées — la planche de
# Kryptonlion a le même objet. Il reste neuf cases sans nom, dont le point d'interrogation
# du sac (227), que le jeu désigne par son fichier : unnamed/frlg_227.
#
# D'où viennent ces noms :
#   - 196 cases sont, pixel pour pixel, le dessin d'une icône nommée de Pokémon
#     Essentials : elles en prennent le nom ;
#   - 219 est le Tri-Passe de FRLG — pokesprite le nomme tri-pass. Le jeu en a fait sa
#     « carte du village » ;
#   - 251 à 266 sont les CT, une par type, appariées à celles du kit par la couleur du
#     disque. La 3ᵉ génération n'a pas de CT Insecte : il n'y en a que seize.
